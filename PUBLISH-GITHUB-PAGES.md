# Enable GitHub Pages

This repository already contains the complete, standalone prototype at `index.html` on branch `main`.

1. Open [Repository Pages Settings](https://github.com/add2go/bittencourt-realty-website/settings/pages).
2. Set **Source:** Deploy from a branch.
3. Set **Branch:** main and **Folder:** /(root).
4. Click **Save**.
5. Wait for GitHub's deployment status to show success.
6. Visit https://add2go.github.io/bittencourt-realty-website/

If Pages initially reports a 404, check the Pages deployment status and refresh after completion.

Do not connect the prototype forms to real customer data. IDX/MLS, Sanity, mail delivery and booking require production implementation.
